# 《紫微斗数全书》要点 · 赋文与格局

> 判断格局、想引一句古籍"压阵"时查阅。是 stars_reference.md 的古典底本：那边讲"这颗星是什么人"，这边讲"古人怎么看这个组合"。
> 《紫微斗数全书》旧题宋·陈希夷著，实为明清托名汇编，传本（如《太微赋》《骨髓赋》《形性赋》各篇）字句互有出入。下文引句取通行本，**引用时说"古书有句话"即可，不要说成"陈希夷说"，更不要逐字担保**。

## 用法

1. 排盘后先看命宫、三方四正（命、财帛、官禄、迁移），对照下面的格局表
2. **成格要看条件**：古书格局几乎都带"庙旺""无煞冲破""某年生人"之类前提，条件不全只能说"有此格局的影子"
3. 引一句赋文 → 马上翻成白话 → 落回用户的现实，三步缺一不可
4. 古书原话常带等级、宿命口吻（"至公卿""夭折""下贱"），**照 interpretation_guide 的铁律改写**：只讲倾向，不下判决

## 一、总纲（《太微赋》等篇的核心观念）

| 观念 | 白话 | 解读时怎么用 |
|------|------|------------|
| 星有庙旺陷，力有强弱 | 同一颗星，在不同宫位能量差很多 | 先查亮度，再谈吉凶 |
| 吉星守照、三方会合 | 命宫好不好，不只看本宫，要看三方四正 | 本宫弱但三方强，照样说"外援足" |
| 吉凶相混，看谁为主 | 吉煞同宫时比力量，不是简单抵消 | 说清"哪股力量占上风" |
| 命好不如身好，身好不如运好 | 先天盘只是底子，大限流年才是走势 | 用户问"我命好不好"，引这句把话题引到运限 |

## 二、吉格（常用十二格）

### 君臣庆会
- **条件**：紫微坐命，左辅右弼、天魁天钺、文昌文曲等吉星会照，无煞冲破
- **赋文**：「紫微辅弼同宫，一呼百诺居上品」
- **白话**：有能力也有人帮，适合当带团队的人。缺辅星则是"孤君"，能干但事事亲力亲为。

### 极向离明
- **条件**：紫微在午宫坐命，无擎羊陀罗等煞忌
- **赋文**：「紫微居午无刑忌，甲丁己命至公卿」
- **白话**：帝星在最亮的位置，格局高、有气场。今天的说法是"天生适合站在台前"，别翻成"能当大官"。

### 府相朝垣
- **条件**：天府、天相在三方会照命宫
- **赋文**：「府相朝垣，千钟食禄」
- **白话**：一个管库、一个管印，稳定与体面兼得。偏向组织里的稳定上升，而不是创业暴发。

### 机月同梁
- **条件**：天机、太阴、天同、天梁在命宫三方四正会合
- **赋文**：「机月同梁作吏人」
- **白话**：古代指当文职小吏，现代对应体制内、专业岗、幕僚、技术管理。稳中求进，不适合大赌。

### 日月并明
- **条件**：太阳、太阴都在庙旺位（如太阳在辰巳、太阴在酉戌一带）会照命宫
- **赋文**：「日月并明，佐九重于尧殿」
- **白话**：一明一暗都亮，能力与人缘兼备，最适合做"辅佐决策的人"。

### 日照雷门
- **条件**：太阳在卯宫坐命，庙旺无煞
- **白话**：朝阳东升，名声运好，适合需要曝光、讲台、对外发声的工作。

### 石中隐玉
- **条件**：巨门在子或午宫坐命，最喜化禄化权
- **白话**：真本事藏在里面，前半段容易被低估，靠专业深耕慢慢发光。**不宜锋芒太早**是这格的要诀。

### 七杀朝斗 / 七杀仰斗
- **条件**：七杀在寅申坐命，对宫或三方见紫微天府
- **赋文**：「七杀朝斗，爵禄荣昌」
- **白话**：狠角色碰上好平台，拼劲能变成实打实的地位。

### 巨日同宫
- **条件**：巨门太阳同宫（寅申），尤其寅宫太阳旺
- **赋文**：「巨日同宫，官封三代」
- **白话**：口才加光明，适合靠表达立身——讲师、律师、媒体、销售管理。

### 火贪 / 铃贪格
- **条件**：贪狼与火星或铃星同宫或对照，贪狼庙旺
- **赋文**：「贪狼火星居庙旺，名振诸邦」
- **白话**：机会来得突然、爆得也猛。必须补一句：**来得快的也去得快**，要提前想好怎么守。

### 文桂文华
- **条件**：文昌文曲在丑未宫同守命宫
- **赋文**：「文桂文华，九重贵显」
- **白话**：才学与表达双强，适合以文字、学术、设计吃饭。

### 禄马交驰
- **条件**：禄存或化禄与天马同宫或会照
- **白话**：越动越有财，适合跨地区、出差多、流动性强的事业。待在原地反而浪费。

## 三、需提醒的格局（改写后再说）

> 这些格局原文多半很吓人。**一律翻成"要注意什么、怎么化解"**，不说"命里注定"。

| 格局 | 条件 | 原文大意 | 星野录式说法 |
|------|------|---------|------------|
| 羊陀夹忌 | 化忌星被擎羊、陀罗前后夹 | 败局、多波折 | 这块领域压力来自两头，要提前留余地，别把鸡蛋放一个篮子 |
| 日月反背 | 太阳太阴皆落陷（太阳在戌亥子、太阴在辰巳午一带） | 劳碌、六亲缘薄 | 付出多回报慢，适合"夜班型"、幕后型路线，也提醒自己别过度消耗 |
| 马头带箭 | 擎羊在午宫坐命 | 原文其实是**先难后成的吉格**：「马头带箭，镇卫边疆」 | 压力型选手，越逆境越能打——这是好话，别说反了 |
| 命无正曜 | 命宫无十四主星 | 原文有「夭折孤贫」之说 | **不要照搬**。空宫借对宫主星看，说成"可塑性强、受环境影响大" |
| 廉贞七杀 | 廉贞七杀同宫（丑未） | 「廉贞七杀，反为积富之人」 | 起步辛苦，但能靠硬功夫攒下家底——注意原文这里是**反转为吉** |
| 刑囚夹印 | 廉贞化忌、擎羊夹天相 | 官非、是非 | 签字、合同、法律类事务要格外谨慎，这是可防的 |

## 五、引用纪律

- 一次解读**最多引两三句**赋文，多了就成了掉书袋
- 引了就要解释，不让用户自己猜古文意思
- 遇到含性别歧视、贵贱等级的古句（如部分女命赋文），**直接不用**，不需要解释为什么不用
- 拿不准某格是否成立时，说"有这个格局的部分条件"，不硬凑
