# 《紫微斗数全书》要点 · 赋文与格局

> 判断格局、想引一句古籍"压阵"时查阅。是 stars_reference.md 的古典底本：那边讲"这颗星是什么人"，这边讲"古人怎么看这个组合"。
> 《紫微斗数全书》旧题宋·陈希夷著，实为明清托名汇编，传本字句互有出入。
> **本文引句已逐句核对**，底本为 iztro 文档所收《紫微斗数全书》卷一至卷三整理本（校对：知秋，github.com/SylarLong/iztro-docs `learn/ancientBook-*.md`）。出处标注格式：〔卷一·太微赋〕。底本"骨髓赋"写作"骨随赋"，本文统一用通行写法。
> 引用时说"古书有句话"即可，不要说成"陈希夷说"。

## 用法

1. 排盘后先看命宫、三方四正（命、财帛、官禄、迁移），对照下面的格局表
2. **成格要看条件**：古书格局几乎都带"庙旺""无煞冲破""某年生人"之类前提，条件不全只能说"有此格局的影子"
3. 引一句赋文 → 马上翻成白话 → 落回用户的现实，三步缺一不可
4. 古书原话常带等级、宿命口吻（"至三公""夭折""孤贫"），**照 interpretation_guide 的铁律改写**：只讲倾向，不下判决

## 一、总纲

| 原文 | 白话 | 解读时怎么用 |
|------|------|------------|
| 「日月最嫌反背，禄马最喜交驰」〔卷一·太微赋〕 | 太阳太阴怕落陷，禄存/化禄与天马喜相会 | 两条最常用的总判断 |
| 「吉有凶星，美玉瑕玷」〔卷一·骨髓赋〕 | 吉格里混了煞星，好东西带瑕疵 | 吉凶同宫时比力量，说清"哪股力量占上风" |
| 「日月最嫌反背乃为失辉，命身定要精求恐差分数」〔卷一·骨髓赋〕 | 看命身要精细，差一点结论就偏 | 提醒自己：时辰不准就别硬断 |

## 二、吉格

### 君臣庆会
- **条件**：「紫微左右同守命是也，更会相武阴妙上」〔卷一·定贵局〕——紫微坐命，左辅右弼同守
- **原文**：「君臣庆会，材善经邦」〔卷一·太微赋〕；「紫微辅弼同宫，一呼百诺居上品」〔卷一·太微赋〕
- **白话**：有能力也有人帮，适合当带团队的人。缺辅星则是"孤君"，能干但事事亲力亲为。

### 紫微居午
- **条件**：紫微在午宫坐命，无擎羊等煞忌；甲、丁、己年生人尤佳
- **原文**：「紫微居午无杀凑，位至三公」〔卷一·骨髓赋〕；另一处作「紫微居午无刑忌，甲丁己命至公卿」〔卷三·论诸星同垣〕
- **白话**：帝星在最亮的位置，格局高、有气场。今天的说法是"天生适合站在台前"，别翻成"能当大官"。
- 注：后世称此格为"极向离明"，书中无此名。

### 府相朝垣
- **条件**：「命无主星，天府居官禄、天相居财帛」〔卷一·定贵局〕；卷三注「命寅申，府相在财帛宫，禄官朝者，上格」
- **原文**：「府相朝垣，千锺食禄」〔卷三·论诸星同垣〕；「府相同来会命宫，全家食禄」〔卷一·骨髓赋〕
- **白话**：一个管库、一个管印，稳定与体面兼得。偏向组织里的稳定上升，而不是创业暴发。

### 紫府朝垣
- **条件**：「紫微、天府于庙旺之地合照命垣」〔卷一·定贵局〕
- **原文**：「紫府朝垣，食禄万钟」〔卷一·骨髓赋〕；「紫府同宫，终身福厚」〔卷一·骨髓赋〕
- **白话**：底盘厚，抗风险能力强。

### 机月同梁
- **条件**：天机、太阴、天同、天梁在命宫三方四正会合；卷三注「命在寅申方论」
- **原文**：「七杀破军宜出外，机月同梁作吏人」〔卷一·骨髓赋〕
- **白话**：古代指当文职小吏，现代对应体制内、专业岗、幕僚、技术管理。稳中求进，不适合大赌。
- 卷三原注：「加吉不论，无吉无杀亦是平常人，凶杀空劫化忌为下格」——成色差别很大，别一见就夸。

### 日月并明
- **条件**：太阳、太阴都在庙旺位会照命宫
- **原文**：「日月并明，佐九重于尧殿」〔卷一·骨髓赋〕
- **白话**：一明一暗都亮，能力与人缘兼备，最适合做"辅佐决策的人"。

### 日照雷门
- **条件**：太阳在卯宫坐命，昼生；卷三作「日照雷门子辰卯地，昼生富贵声扬」
- **原文**：「日照雷门富贵荣华，月朗天门进爵封侯」〔卷一·骨髓赋〕
- **白话**：朝阳东升，名声运好，适合需要曝光、讲台、对外发声的工作。

### 石中隐玉
- **条件**：巨门在子或午宫坐命，喜化科化权化禄；卷三注「辛癸人上格，丁己人次之」
- **原文**：「子午巨门，石中隐玉」〔卷一·骨髓赋〕；「巨门子午科权禄，石中隐玉福兴隆」〔卷三·论诸星同垣〕
- **白话**：真本事藏在里面，前半段容易被低估，靠专业深耕慢慢发光。**不宜锋芒太早**是这格的要诀。

### 七杀朝斗 / 仰斗
- **条件**：七杀在寅申子午坐命，对宫或三方见紫微天府；卷三作「七杀寅申子午，一生爵禄荣昌」
- **原文**：「七杀朝斗，爵禄荣昌」〔卷一·骨髓赋〕；「朝斗仰斗，爵禄荣昌」〔卷一·骨髓赋〕
- **白话**：狠角色碰上好平台，拼劲能变成实打实的地位。

### 巨日同宫
- **条件**：巨门太阳同宫（寅申），尤其寅宫太阳旺
- **原文**：「巨日同宫，官封三代」〔卷一·骨髓赋〕
- **白话**：口才加光明，适合靠表达立身——讲师、律师、媒体、销售管理。

### 贪火 / 贪铃
- **条件**：贪狼与火星或铃星同宫或三合，贪狼庙旺
- **原文**：「贪狼火星居庙旺，名镇诸邦」〔卷一·骨髓赋〕
- **白话**：机会来得突然、爆得也猛。必须补一句：**来得快的也去得快**，要提前想好怎么守。
- 注："火贪格""铃贪格"是后世叫法。

### 文桂文华
- **条件**：文昌文曲在丑未宫同守命宫
- **原文**：「文桂文华，九重贵显」〔卷一·骨髓赋〕
- **白话**：才学与表达双强，适合以文字、学术、设计吃饭。

### 禄马交驰
- **条件**：禄存或化禄与天马同宫或会照
- **原文**：「禄马最喜交驰」〔卷一·太微赋〕；「武曲禄马交驰，发财远郡」〔卷三·论诸星同垣〕
- **白话**：越动越有财，适合跨地区、出差多、流动性强的事业。待在原地反而浪费。

### 廉贞七杀
- **条件**：廉贞七杀同宫（丑未），庙旺
- **原文**：「廉贞七杀，反为积富之人」〔卷一·骨髓赋〕；卷三补「若陷地化忌，贫贱残疾」
- **白话**：起步辛苦，但能靠硬功夫攒下家底。注意原文是**反转为吉**，但落陷化忌时要降级说。

## 三、需提醒的格局（改写后再说）

> 这些格局原文多半很吓人。**一律翻成"要注意什么、怎么化解"**，不说"命里注定"。

| 格局 | 条件 | 原文 | 研究所式说法 |
|------|------|------|------------|
| 羊陀夹忌 | 化忌星被擎羊、陀罗前后夹（如命申逢忌，羊酉陀未） | 「羊陀夹忌为败局」〔卷三·论诸星同垣〕 | 这块领域压力来自两头，要提前留余地，别把鸡蛋放一个篮子 |
| 日月反背 | 太阳太阴皆落陷 | 「日月最嫌反背乃为失辉」〔卷一·骨髓赋〕 | 付出多回报慢，适合幕后型、长线型路线，也提醒自己别过度消耗 |
| 马头带剑 | 擎羊在午宫坐命 | **书中两说并存**：「马头带剑，镇卫边疆」〔卷一·太微赋〕；又「马头带剑，非夭折则主刑伤」〔卷一·骨髓赋〕。卷三另有「天同贪羊陀居午位，丙戌镇御边疆，为马头带箭，富且贵」 | 压力型选手，逆境里能打，但要防冲动受伤。**只说两面性，不说夭折** |
| 命无正曜 | 命宫无十四主星 | 「命无正曜，夭折孤贫」〔卷一·骨髓赋〕；卷三又作「命无正曜，二姓延生」 | **不要照搬**。空宫借对宫主星看，说成"可塑性强、受环境影响大" |
| 刑囚夹印 | 廉贞（囚）、擎羊（刑）与天相（印）同会；书注「天刑廉贞同临身命」 | 「刑囚夹印，刑杖惟司」〔卷一·太微赋〕；书注又说此格「主武勇之人」 | 签字、合同、法律类事务要格外谨慎，这是可防的；也可能走执法、纪律类赛道 |

## 五、引用纪律

- 一次解读**最多引两三句**原文，多了就成了掉书袋
- 引了就要解释，不让用户自己猜古文意思
- 遇到含性别歧视、贵贱等级的古句（如部分女命赋文），**直接不用**，不需要解释为什么不用
- 拿不准某格是否成立时，说"有这个格局的部分条件"，不硬凑
- 想引本文件以外的句子，先去底本里找到原文再引，**不凭印象引古书**
