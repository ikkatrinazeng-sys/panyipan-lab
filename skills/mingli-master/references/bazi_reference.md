# 八字（四柱）解读参考 · 三派融合口径

> 用户要看八字时查阅。排盘交给 `scripts/calculate_bazi.py`，**不手算四柱**。
> 本文件定的是"怎么看"：**调候为先、格局为体、旺衰为用**。
> 引文已逐句核对，底本为 github.com/lineeks/ancient-text-library 的 `raw/` 目录（MIT）：
> 《子平真诠评注》`zipingzhenquan.txt`、《滴天髓阐微》`ditiansuichanwei.txt`、《穷通宝鉴》`qiongtongbaojian.txt`。〔行号〕为底本行号。
> 注意：底本《子平真诠》是徐乐吾评注本，原文与评注混排，下面凡评注都标明"徐注"；《滴天髓》是任铁樵阐微本，"原注"指旧注、"任氏曰"指任注。

## 一、排盘口径（已定，脚本照此执行）

| 项 | 口径 | 理由 |
|---|---|---|
| 子时 | **23:00 起即换日**，日柱、时柱都算次日 | 子时一阳生，干支在 23 点交替；不用"夜子时日柱算当天"的杂说 |
| 真太阳时 | **必须校正**，与紫微盘同一套（经度时差，可加均时差） | 北京时间只是行政标准；西部出生不校正，时柱会系统性偏 |
| 年 / 月柱 | 立春换年，节气换月 | 子平通例 |
| 大运 | 阳男阴女顺排，阴男阳女逆排；**3 天折 1 岁、1 天折 4 个月、1 个时辰折 10 天**，精确到岁月日 | 交运前后的流年要看得出交接 |
| 神煞 | **不排** | 子平正统弃神煞，免得干扰生克判断 |
| 十二长生 | **保留**，作"有气无气"的辅助参考 | 日主在月令的长生状态是看旺衰的直观刻度 |

用法：

```
python3 scripts/calculate_bazi.py --solar 1995-4-29 --time 10:00 --city 郴州 --gender 女 --output /tmp/bazi.json
# 城市未收录时传经度：--longitude 112.9；要更精确加 --eot
# 出生地完全不知道才用 --no-true-solar，并在解读里说明时柱可能有偏差
```

只支持公历输入。用户给农历时，先换成公历再排（问清是否闰月）。

输出 JSON 里解读要用到的字段：

| 字段 | 用途 |
|---|---|
| `bazi` / `pillars` | 四柱、十神、藏干、纳音、旬空 |
| `pillars.*.xingyun` | 日主在各支的十二长生（"星运"） |
| `pillars.*.zizuo` | 各柱天干在本支的十二长生（"自坐"） |
| `yueling` | 月令、季节、寒暖燥湿、`tiaohou_urgent`（寒/暖/无）、本气、前后节气 |
| `day_master.yueling_xingyun` | 日主在月令的长生状态，旺衰第一参考 |
| `wuxing_count` | 五行计数（仅作粗看，**不能代替旺衰判断**） |
| `qiyun` / `dayun` | 起运时间、交运日、各步大运 |
| `true_solar_time_correction` | 真太阳时校正详情；跨时辰时**必须告诉用户** |

**节气交接要提醒**：出生日离 `yueling.prev_jie` 或 `next_jie` 只有一两天时，月柱对出生时间很敏感，要告诉用户"出生时间差几个小时，月柱就会变"。

## 二、解读三步法

### 第一步：定调候（《穷通宝鉴》）

先看出生季节的寒暖燥湿。**严冬、酷暑生人，调候永远排第一**：调候失了，格局再好也打折。

- 查 `yueling.tiaohou_urgent`：`寒` = 亥子丑月，急需火暖；`暖` = 巳午未月，急需水润；`null` = 春秋，调候不急，可直接看格局
- 查 `references/qiongtong_tiaohou.md`：日主那一节、出生月那一行，原文直接写着取什么用神（如「十一月甲木，木性生寒，丁先庚後，丙火佐之」〔88〕）
- 再看四柱里有没有这个调候之神、透干还是藏支

经典依据：
- 《子平真诠》：「论命惟以月令用神为主，然亦须配气候而互参之。」〔191〕——子平本身也承认格局要配气候
- 《子平真诠》徐注："调候。金水生于冬令，木火生于夏令，气候太寒太燥，以调和气候为急。此以调候为用神也。"〔126〕
- 《滴天髓》：「天道有寒暖，发育万物，人道行之，不可过也。」〔3129〕；「地道有燥湿，生成品汇，人道得之，不可偏也。」〔3186〕（底本"品汇"误作"品泯"）
- 《滴天髓》原注："过于湿者，滞而无成；过于燥者，烈而有祸。"〔3187〕

### 第二步：立格局（《子平真诠》）

以月令定格，看这个八字的"赛道"和层次。

- 取 `yueling.benqi`（月令本气）及月令藏干中**透出天干**的那个，定其十神，就是格（正官格、七杀格、正财格、食神格……）
- 月令是比劫（建禄、月刃）时本身不能为格，另看四柱透干会支的财官煞食
- 辰戌丑未月是"杂气"，藏干多，看哪个透出

经典依据：
- 「八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。」〔121〕
- 「财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。」〔121〕
- 「然亦有月令无用神者，将若之何？如木生寅卯，日与月同，本身不可为用，必看四柱有无财官煞食透干会支……」〔134〕
- 「四墓者，杂气也，何以谓之杂气？以其所藏者多，用神不一，故谓之杂气也。」〔219〕
- 「成中有败，必是带忌；败中有成，全凭救应。」〔142〕——格成了还要看有没有破格的东西，破了有没有救

**顺用 / 逆用**速记：财、官、印、食是"善神"，要护着（顺用）；七杀、伤官、劫财、羊刃是"凶神"，要制化（逆用）。

### 第三步：看旺衰，定喜忌（《滴天髓》）

看日主强弱、五行流通，最后定用神喜忌，推大运流年吉凶。

- 先看 `day_master.yueling_xingyun`：长生、冠带、临官、帝旺 = 得令；衰、病、死、墓、绝 = 失令；沐浴、胎、养介于两者之间，要结合全局
- 再看四柱有无比劫、印星帮身（得地、得助）
- **不能只数五行个数**：`wuxing_count` 只是粗看，要看是否得令、通根、透干

经典依据：
- 「能知衰旺之真机，其于三命之奥，思过半矣。」〔1614〕
- 原注：「旺则宜泄宜伤，衰则喜帮喜助，子平之理也。然旺中有衰者存，不可损也；衰中有旺者存，不可益也。」〔1615〕（底本"衰中"误作"衰右"）
- 「月令乃提纲之府，譬之宅也，人元为用事之神，宅之定向也，不可以不卜。」〔1579〕
- 「既识中和之正理，而于五行之妙，有全能焉。」〔1897〕

### 三步冲突时怎么裁

1. **调候急（严冬酷暑）**：调候之神优先，格局用神退居第二
2. **调候不急（春秋）**：以格局为主，旺衰定喜忌
3. **格局用神与旺衰喜忌打架**（比如官格但日主太弱担不起官）：以旺衰为准定喜忌，格局只用来说层次和赛道
4. 极旺极弱、成从格化格的，按《滴天髓》"从""化"论，**拿不准就直说拿不准**

## 三、白话输出结构

1. **底色**：日主是什么（"你是一棵冬天的甲木"），生在什么季节，冷还是热
2. **最缺什么**：调候结论，翻成生活语言（"你需要的是温度和光——热情的环境、能点燃你的人"）
3. **赛道**：格局对应的人生方向（正官格 → 体制、规则、管理；食伤格 → 表达、创作、技术）
4. **强弱与喜忌**：身强身弱，喜什么五行，翻成行业、方位、颜色只作参考
5. **大运**：当前大运和下一步大运；交运日给到具体日期
6. **边界**：八字能说倾向和时机，说不了具体的人和具体的事

## 四、禁忌（八字特有）

- 古书里"克妻""克子""夭折""贫贱""残疾""僧道"这类断语，**一律不转述**，只用来辅助判断用神成败
- 不用"身弱就是命不好"的说法：身弱身强只是结构，不是好坏
- 紫微和八字结论不一致时，**两边都说，不强行调和**；告诉用户这是两套系统
