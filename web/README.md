# 盘一盘研究所 · 网页版

手机浏览器直接打开 `panyipan.html` 就能用，所有排盘都在本地计算，不需要服务器。

- 开场：电子木鱼（浑厚的大木鱼声），敲九下进入排盘
- 输入：性别、公历 / 农历（含闰月）、精确时间或时辰、省 / 市（全国地级市，自动查经度做真太阳时校正）
- 结果：验盘（用过去的事检验命盘）· 会诊（紫微、八字两派分别给结论）· 命盘 · 今年 · 合盘
- 每条结论都可以展开看"研究依据"

## 修改后重新打包

```bash
cd web
npm i iztro esbuild   # 第一次需要
./build.sh            # 生成 panyipan.html
```

排盘与解读逻辑在 `../miniprogram/utils/`（chart.js、insight.js、solar-time.js），网页版和小程序版共用。
